# Segurança

Achou uma falha de segurança? **Não abra uma issue pública.** Use a aba **Security → Report a vulnerability** deste repositório para mandar um relato privado aos mantenedores.

Inclua o que acontece, como reproduzir e qual versão (commit) você está usando. Respondemos o mais rápido possível e combinamos com você quando publicar a correção.
