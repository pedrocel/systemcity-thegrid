# Código de Conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: trate todo mundo com respeito, critique ideias e não pessoas, e acolha quem está chegando. Assédio, ataques pessoais e linguagem discriminatória não são aceitos em issues, Pull Requests, discussões ou qualquer outro espaço do projeto.

Para relatar um comportamento inaceitável, abra um relato privado pela aba **Security → Report a vulnerability** do repositório, ou fale com os mantenedores. Todo relato é tratado com sigilo.
